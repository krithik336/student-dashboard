#  Student Performance Dashboard

An interactive data analytics and machine learning project built using Python and Streamlit.  
This dashboard analyzes student performance and provides predictive insights based on academic data.

---

##  Live Demo

🔗 https://student-dashboard-5xp2hcthqepcqim3xbtp39.streamlit.app/

---

##  Project Overview

This project focuses on analyzing student performance using data visualization and machine learning techniques.  
It transforms raw data into meaningful insights and allows users to interact with the data through a dynamic dashboard.

---

##  Key Features

- 📊 Data Cleaning & Preprocessing  
- 📈 Interactive Visualizations (Seaborn & Matplotlib)  
- 🎯 KPI Metrics (Average, Max, Min Scores)  
- 🔍 Dynamic Filters (Gender, Test Preparation, etc.)  
- 🔮 Machine Learning Prediction (Math Score)  
- 📄 Dataset Preview & Download Option  
- 🌐 Live Deployment using Streamlit Cloud  

---

##  Machine Learning Model

- Model Used: **Linear Regression**
- Input Features: Reading Score, Writing Score  
- Target Variable: Math Score  

The model predicts a student’s math score based on reading and writing performance.

---

##  Key Insights

- Students who completed test preparation scored significantly higher  
- Strong positive correlation between reading and writing scores  
- Majority of students fall within the mid-performance range  
- External factors like preparation influence academic outcomes
